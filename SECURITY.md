# Security reporting

This repository is an intentionally vulnerable demo site. It exists to show what the UNPWNED scanner detects, so the weaknesses in it are planted on purpose. Please do not report them, and do not deploy this code as a real application.

## A vulnerability in UNPWNED itself

Report privately to [security@unpwned.io](mailto:security@unpwned.io), following [UNPWNED's vulnerability disclosure policy](https://www.unpwned.io/security).

This repository does not expand authorization to test UNPWNED's hosted services, GitHub, or any third party. The disclosure policy linked above defines the reporting process and scope for those.

## UNPWNED Academy practice

The hosted copy of this site at demo.unpwned.io is the practice site of [UNPWNED Academy](https://www.unpwned.io/academy). UNPWNED gives one limited permission to send it requests, in [Section 11b of the UNPWNED Terms of Service](https://www.unpwned.io/terms): the individual requests that an Academy station displays, one at a time and as displayed, in order to follow the course. That permission covers demo.unpwned.io only and no other UNPWNED host. It does not cover automated scanning, path or credential guessing, load or volumetric testing, any request the course does not display, or the infrastructure of the provider that hosts the site. The hosted site is not a research target under the vulnerability disclosure policy. The Terms are the authority, and nothing in this repository widens them.
